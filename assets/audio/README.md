# Lobby BGM Audio Assets

로비 화면 배경음악(BGM)으로 재생할 오디오 파일을 아래 경로에 배치하세요.

- **파일 경로**: `assets/audio/lobby_bgm.mp3` (MP3 / OGG / M4A 중 `.mp3` 권장)
- 파일 배치 후 `flutter build web` 또는 `flutter build apk --release` 로 빌드하면 웹과 Android APK 모두에서 자동으로 루프 재생됩니다.
- 저작권 보호 음원(예: 상업 게임 OST)은 공개 저장소 커밋 대신 개인 빌드용 로컬 배치 또는 로열티 프리 음원 사용을 권장합니다.
